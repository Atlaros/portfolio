# Referencias visuales y límites de veracidad

## A. Diseño elegido

`reference/hero-dark-engineering-premium.png` corresponde a la imagen de propuesta visual generada en la conversación. **Es referencia de estilo y composición, no screenshot de las aplicaciones ni mockup funcional validado**.

Dirección visual a extraer:
- Fondo profundo azul-negro, cian protagonista, azul eléctrico para profundidad.
- Gran título BLANCO sin degradados multicolor, acento pequeño.
- Composición editorial izquierda + escenario de producto inmersivo a derecha.
- Selector de proyecto y vista visual que cambia; profundidad contenida.
- Transición hacia casos destacados, con TramitIA grande y otros proyectos de apoyo.

Lo que **NO** debe copiarse literalmente:
- La UI simulada de TramitIA, formularios, paneles de resultados y sus textos como si fueran capturas reales.
- Plazos, cantidad de requisitos, supuesta verificación, procedimientos, fichas, fuentes de datos o funcionalidades mostradas solo en la ilustración.
- Diagramas que sugieren un número/tipo de agentes o fuentes distinto a la arquitectura real.
- Etiquetas como «piloto activo» si no se verificó el despliegue vigente.
- Tags RAG en AcademIA o funciones no verificadas; gráficos de ranking o mapas como resultados técnicos medidos.

**Sustitución:** capturas/diagramas genuinos o composición editorial neutra etiquetada «ilustrativa» (no demo de producto). Mantener una hoja de trazabilidad por proyecto con fuente de cada afirmación.

`reference/antes-hero.png` es una captura suministrada por el usuario de la interfaz anterior; se conserva únicamente para evaluar el cambio visual. No debe desplegarse en el producto.
