# ADR-002 — Contenido de proyectos en MDX

**Estado:** Aprobado para MVP

## Decisión
Gestionar proyectos y case studies mediante MDX + metadata validada.

## Motivos
- Fácil versionado.
- Sin CMS ni DB.
- Permite contenido rico.
- Escala bien para 5–15+ proyectos.

## Revisión
Revisar si editar contenido desde una UI se vuelve requisito.
