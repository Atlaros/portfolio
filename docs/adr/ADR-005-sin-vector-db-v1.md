# ADR-005 — Sin vector DB en V1

**Estado:** Aprobado para MVP

## Decisión
Usar recuperación determinista basada en metadata, títulos, keywords y contenido estructurado.

## Motivos
Con 5 proyectos, una vector DB añade coste y complejidad innecesaria.

## Revisión
Reevaluar con 15+ proyectos o corpus profesional mucho más grande.
