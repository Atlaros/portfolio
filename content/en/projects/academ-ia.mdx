title: AcademIA
tagline: Finding studies in Bolivia, starting with Santa Cruz
summary: A searchable academic catalog with university browse and side-by-side comparison. The app was packaged for a single-instance AWS EC2 host; this portfolio does not list a public demo URL.
problem: Academic offerings are scattered across sources, so comparing programs, requirements, modality, and timing is slow and inconsistent.
whyItMatters: Prospective students need a unified discovery path that starts in Santa Cruz with national-scope intent, without announced clients or partnerships.
solution: A searchable catalog with university browse, side-by-side program comparison, and account-specific flows, built as a Next.js monolith over normalized program data.
approach: Architecture separates three layers. The application is a Next.js service with PostgreSQL, Supabase Auth plus an application session cookie, Docker, and a documented single-host AWS EC2 path (runner image and Caddy). The editorial catalog is curated primarily in local Postgres, with an authorized transfer plan toward Supabase for hosted environments. Published program rows in that catalog are editorial publications inside the product database, not a claim that a public website is currently online.
engineeringDecisions:
  - Heterogeneous program data is normalized before search and comparison.
  - Verified enrollment information is distinguished from unconfirmed fields.
  - Structured filters support discovery without implying complete national coverage.
  - Hosting targets a single EC2 instance with Docker and Caddy; the portfolio does not publish a live demo URL.
  - Catalog transfer to a hosted database is treated as an explicit, authorized step—not an automatic side effect of building the app.
validation: Editorial review gates source material before program rows are marked published in the catalog. Production-style checks documented for the deploy path include health and explore flows; no public uptime or accuracy KPIs are claimed here.
benefits:
  - Unifies discovery and comparison of academic offerings starting from Santa Cruz.
  - Supports side-by-side comparison of programs of the same type.
  - "Separates the deployed application path, the local editorial catalog, and what is marked published in data."
limitations: No public demo URL is listed on this site. Catalog counts visible in screenshots are not current verified KPIs. A past or prepared AWS host does not imply continuous public availability.
